LANDING PAGE EXPLANATION

Topic: Technology Product / Technology Company (TechNova)

Where CSS Grid Was Used:
- The main content area uses CSS Grid through the .grid-layout class.
- grid-template-columns: repeat(auto-fit, minmax(250px, 1fr))
- gap property used for spacing.

Where Flexbox Was Used:
- Navigation bar (.navbar)
- Navigation links (.nav-links)
- Hero section alignment
- Features section (.features)
- Team section (.team)

This project demonstrates both CSS Grid and Flexbox, responsive design, spacing, alignment, and clean code structure.
